      FAQ
      
Questions before installing

    

    

      

        Is Quoted an SEO plugin?
        
Quoted is best understood as an AI visibility and content-structure layer for WordPress. It helps AI crawlers and assistants understand your content more clearly. It does not replace a traditional SEO plugin.

      

      

        Does it replace Yoast, Rank Math, AIOSEO, or SEOPress?
        
No. Keep your SEO plugin for titles, meta descriptions, XML sitemaps, and search workflows. Quoted adds /llms.txt, clean Markdown, AI bot tracking, crawler controls, and compatible schema.

      

      

        Does it guarantee ChatGPT or Google AI visibility?
        
No. No plugin can guarantee AI visibility, citations, rankings, or traffic. Quoted helps prepare and structure your content so AI systems have clearer source material to read.

      

      

        Will it slow down my website?
        
Quoted is designed to be lightweight. Bot detection is a simple user-agent check, /llms.txt is cached, and the Free plan does not call an external service.

      

      

        Do I need technical skills?
        
No. The Free workflow is built for ordinary WordPress admins. Advanced users can still review outputs, crawler rules, and settings.

      

      

        Can agencies use it for clients?
        
Yes. Pro is designed for freelancers and small agencies that want a repeatable AI-readiness setup across client WordPress sites.

      

      

        Will my data be sent to Quoted servers?
        
The Free plan operates locally on your WordPress site and does not send telemetry to Quoted. Paid AI checks use your own provider key where applicable.

      // Update stat numbers
      shift.querySelectorAll('[data-stat]').forEach(el => {
        el.textContent = el.dataset[state];

      shift.querySelectorAll('[data-stat-em]').forEach(el => {
        el.textContent = el.dataset[state];
      });
    };
    shift.querySelectorAll('.shift-btn').forEach(b => {
      b.addEventListener('click', () => setState(b.dataset.shift));
    });
    document.getElementById('shift-switch')?.addEventListener('click', () => {
      setState(shift.dataset.quotedState === 'on' ? 'off' : 'on');
    });

    // Auto-flip once when first scrolled into view (so visitors see the payoff)
    let played = false;
    const io = new IntersectionObserver((entries) => {
      entries.forEach(e => {
        if (e.isIntersecting && !played) {
          played = true;
          setTimeout(() => setState('on'), 1400);
        }
      });
    }, { threshold: 0.45 });
